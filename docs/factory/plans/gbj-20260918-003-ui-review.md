### ✅ 6. Workspace commit does not skip Refresh confirm

function commitWorkspace(typed: string) {
  const live = workspaceSlug || committedWorkspace;
  const decision = commitWorkspaceSlug(live, typed);
  if (decision.action !== "commit") return;
  const nextFlags = setWorkspaceFlag(flags, decision.slug);

  setWorkspaceSwitch(pending);
  setFlags(nextFlags);
  setWorkspaceSlug(decision.slug);
  openRefreshConfirm(nextFlags);
}
\`\`\`

Line 1417: `openRefreshConfirm(nextFlags)` always opens the dialog. No silent POST. The existing `refreshOpen` state and `<AlertDialog>` are reused.

### ✅ 9. Empty slug rejected; blur without Enter discards

**Evidence:** `src/flags.ts:107-115` and `src/App.tsx:1139-1146`

\`\`\`typescript
export function commitWorkspaceSlug(
  liveSlug: string,
  typed: string,
): { action: "reject" } | { action: "noop" } | { action: "commit"; slug: string } {
  const slug = typed.trim();
  if (!slug) return { action: "reject" };
  if (slug === liveSlug) return { action: "noop" };
  return { action: "commit", slug };
}
\`\`\`

Line 112: Empty slug after trim returns `{ action: "reject" }`. The caller (`commitWorkspace` at line 1409) returns early on `"reject"`, leaving flags and pill unchanged.

Blur handler:

\`\`\`typescript
onBlur={() => {
  if (skipBlur.current) {
    skipBlur.current = false;
    return;
  }
  setDraft(slug);
  setEditing(false);
}}
\`\`\`

Line 1145: `setDraft(slug)` restores the live slug. Line 1146: `setEditing(false)` returns to button state. No commit, no dialog.

Enter commits:

\`\`\`typescript
onKeyDown={(event) => {
  if (event.key !== "Enter") return;

  skipBlur.current = true;
  setEditing(false);
  onCommit(draft);

\`\`\`

Line 1152: `onCommit(draft)` is called only on Enter. Blur is suppressed via `skipBlur` to avoid double-fire.

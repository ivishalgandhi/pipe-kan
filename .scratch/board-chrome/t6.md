## What to build

Folders organize Favourites the way Linear does, locally and persisted. One level only: a Folder holds Favourites, not other Folders. Create, rename, and delete from the Favourites header menu. Move a Favourite into a Folder (or unfile it) from a small menu on the row. No drag this cut.

A Favourite lives in at most one Folder: unfiled, or in exactly one. Star still Favourites; Folder is where that pin lives. Unfiled Favourites sit first (still P1–P3, then Issue key A–Z). Then Folders A–Z. Inside a Folder, the same priority rank. Folder collapse persists, default open. An empty Folder stays visible until the user deletes it.

Delete unfiles its Favourites; they stay starred. Search omits a Folder whose name does not match and none of whose children match; the Folder stays stored. Folder names are unique case-insensitively; a colliding create or rename is rejected in the menu.

Persist Folders with Favourites (the same store as `favourite-epics`, grown to hold folders). Not the Filter / Sort / Hide blob.

## Acceptance criteria

- [ ] Favourites header can create a named Folder. Create, rename, and delete are menu actions. No drag-reorder.
- [ ] A row menu moves a Favourite into a Folder or unfiles it. A Favourite is unfiled or in exactly one Folder.
- [ ] Unfiled Favourites paint first (shared priority rank, then Issue key A–Z). Then Folders A–Z. Inside a Folder, the same rank.
- [ ] Folder collapse persists, default open. An empty Folder stays visible until deleted.
- [ ] Deleting a Folder unfiles its Favourites. They stay starred.
- [ ] Search omits a Folder when its name misses and none of its children match. The Folder stays stored.
- [ ] Folder names are unique case-insensitively. A colliding create or rename is rejected in the menu.
- [ ] Folders persist with Favourites, not in the Filter / Sort / Hide blob. Clearing Filter does not wipe Folders.
- [ ] Tests sit next to Favourite tests: one-home, unfile-on-delete, Search omits a non-matching empty Folder, name collision rejected, order unfiled-then-Folders. Menu chrome is not tested.

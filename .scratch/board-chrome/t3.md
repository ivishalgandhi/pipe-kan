## What to build

Hide takes a Column off the Board until the user puts it back. Collapse stays the chevron. Empty statuses stay omitted (not Hidden). Hide is app-owned: ReUI Kanban has no Hide API.

Restore from a Columns picker in the header (third ghost Button, next to Filter and Sort). Also Hide from a control on the Column itself, next to the collapse chevron. Cards in a Hidden Column stay in memory so Search, Refresh, and Move do not drop them. Drops onto a Hidden Column are rejected. The last Column may be Hidden (empty Board is allowed). Hidden names live in the same last-used blob as Filter and Sort.

## Acceptance criteria

- [ ] A Columns dropdown in the header lists statuses from the in-memory Board. Unchecked = Hidden. Checking restores the Column.
- [ ] A Hide control on the Column, next to the collapse chevron, Hides that Column. The chevron still only collapses.
- [ ] Hidden Columns are omitted from the painted Board. Their Cards remain in memory.
- [ ] A drop onto a Hidden Column does nothing (no Move).
- [ ] The last visible Column may be Hidden. Empty Board is allowed. Restore from the Columns picker.
- [ ] Empty statuses with no Issues remain omitted and are not listed as Hidden.
- [ ] Hide persists in the last-used Filter / Sort / Hide blob. Next visit restores Hidden Columns.
- [ ] Tests extend the visibility seam: Hide omits a Column while Cards remain in the input; merge/rollback still restore Cards that Filter or Search hid; a Hidden Column is not a drop target. Picker chrome is not tested.

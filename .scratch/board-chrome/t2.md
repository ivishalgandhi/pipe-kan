## What to build

Filter and Sort sit in the header as ReUI/shadcn dropdowns (ghost Buttons), left of Refresh. Filter hides Cards without changing Scope or Refresh. Sort orders Cards inside each Column. First visit: no Filter, payload order. After that, last-used Filter, Sort, and Hide persist in one local blob (Hide starts empty on this ticket). Search stays session-only. A clear control resets the blob.

First-cut Filter: priority (multi) and assignee (multi), plus Unassigned. Options come from Cards in memory. Filter ANDs with Search and the selected Epic, and applies only to Board Cards. A Column with no remaining Cards after Filter or Search is omitted; clearing Filter brings it back (that is not Hide).

First-cut Sort: one of payload order, priority, age, due date, key. Per Column. No reverse. Priority rank: P1 / Highest / Critical, then P2 / High, then P3 / Medium, then lower, then missing. Age oldest first. Due soonest first. Key A–Z. Missing Sort field last; ties by Issue key A–Z. Stale last-used Filter is kept even if Refresh leaves no matching Cards.

## Acceptance criteria

- [ ] Header has Filter and Sort ghost Buttons left of Refresh, using ReUI/shadcn DropdownMenu. No new header layout.
- [ ] Filter by priority (multi) and assignee (multi). Unassigned is a Filter value. Options come from Cards in memory.
- [ ] Filter ANDs with Search and the selected Epic. The Epic pane does not change when Filter changes.
- [ ] A Column with no remaining Cards after Filter or Search is omitted. Clearing Filter restores it if it still has Cards and is not Hidden.
- [ ] Sort is one of payload order, priority, age, due date, key. Applied per Column. No reverse toggle.
- [ ] Priority Sort uses the shared rank (P1 / Highest / Critical, then P2 / High, then P3 / Medium, then lower, then missing). Age oldest first. Due soonest first. Key A–Z. Missing field last; remaining ties by Issue key A–Z.
- [ ] First visit: empty Filter, payload order. Later visits restore the last-used blob (Filter + Sort + Hide; Hide empty until the Hide ticket). Search is not persisted.
- [ ] A stale last-used Filter is kept even if Refresh leaves no matching Cards. A clear control resets the blob to first-visit chrome.
- [ ] Tests drive the existing visibility seam (the function that turns in-memory Columns plus Search, Epic, Filter, and Sort into the painted Board, and its merge/rollback cousins). Dropdown markup and localStorage wiring are not tested.

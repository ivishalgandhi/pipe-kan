## Acceptance criteria

- [ ] Pill is visible only when board `kind === "plane"`. Jira never shows it, even if Scope flags contain `--plane`. Plane keeps it even if `--plane` is deleted from flags.
- [ ] Pill sits beside the project-identifier chip, shows the resolved live slug, accessible name **Workspace** (not Project).
- [ ] Click to type. Enter commits (trim). Blur without Enter discards. Empty rejected. Same live slug is a no-op (no dialog).
- [ ] Commit writes `--workspace <slug>` into Scope flags (including `personal`) and opens the existing Refresh dialog. That confirm is always Refresh **all**; Refresh selected stays visible and disabled. Title stays **Refresh**. Copy names the target slug. Primary remains **Refresh all Epics**.
- [ ] Header Refresh and Command Refresh keep the normal all-or-selected dialog.
- [ ] Cancel restores the pre-commit flags string and the last successful slug. Do not POST. Do not invent `--workspace` on Cancel if it was not in flags.
- [ ] Failed Refresh keeps the attempted flags and pill, keeps the previous Board, uses the existing Plane error toast.
- [ ] After **successful** all-Refresh to a different resolved Workspace, Favourites reset (same idea as the `--projects` stamp). Cancel and failed Refresh leave Favourites alone. Filter / Sort / Hide / Presets stay last-used.
- [ ] `--projects` is not changed. No list-workspaces. No last-used slug persistence. No Command overlay row. No Google SSO. No React test runner — ui-review is the extra-checker.
- [ ] `feat:` on `feat/plane-workspace-switcher`. Do not merge PR #58. Do not bump package.json or run semantic-release. No real tenant names in git.

# Triage

Read the issue and classify it with exactly one of these labels:

- `needs-triage` — still needs maintainer evaluation
- `needs-info` — waiting on reporter for more information
- `ready-for-agent` — fully specified, safe for an AFK agent to pick up
- `ready-for-human` — requires human judgment or sensitive decision
- `wontfix` — will not be actioned

Explain your classification in one sentence. If `needs-info`, list the specific questions to ask the reporter. If `ready-for-agent`, name the acceptance criteria that make it safe.

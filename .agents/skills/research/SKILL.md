# Research

Investigate the user's question against primary sources: official docs, source code, specs, first-party APIs. Avoid secondary write-ups.

Structure your final answer as:
1. One-sentence conclusion.
2. Bullet list of claims, each with a cited source URL.
3. Open questions or risks.

If the topic is about ACP, Agent Client Protocol, Cursor, Devin, or LLM agent tooling, prefer sources at agentclientprotocol.com, cursor.com/docs, docs.devin.ai, and the official SDK repos.
